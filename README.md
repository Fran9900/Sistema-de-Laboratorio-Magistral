# Sistema de Gestión y Administración de Laboratorio Magistral

Sistema integral para la trazabilidad y gestión operativa de preparados magistrales.

## Estructura Base del Proyecto

- `backend/`: API REST desarrollada con Node.js y Express.
- `frontend/`: Aplicación SPA desarrollada con React, Vite y Tailwind CSS.
- `database/`: Scripts de base de datos MySQL (DDL y DML).
- `scripts/`: Scripts de soporte, inicialización y mantenimiento.
